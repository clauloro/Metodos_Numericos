# Métodos Numéricos – Caso de Uso 1  

**Modelización del comportamiento del metano**

Este repositorio contiene el desarrollo completo del Caso de Uso 1 de la asignatura de Métodos Numéricos. Se modela el comportamiento termodinámico del metano a través de métodos de interpolación, regresión y resolución de ecuaciones de estado reales (como Peng–Robinson), así como del cálculo del coeficiente de virial.
